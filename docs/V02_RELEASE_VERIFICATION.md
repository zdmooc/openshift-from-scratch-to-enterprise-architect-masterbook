## Limites de l'édition

Le PDF de 59 pages est une **première édition technique condensée**, pas la version développée de 200–280 pages envisagée à l'origine. Les schémas Mermaid sont reproduits sous forme de source et devront être rendus graphiquement dans une future édition.

Le livre-source dans GitHub est la référence éditoriale ; les correctifs futurs nécessiteront une nouvelle édition avec version et errata.
